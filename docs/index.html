Assignment 1: Deep Learning and SVM Classification

Comparative study of ResNet-18 and ResNet-50 on MNIST and FashionMNIST datasets, with SVM baseline comparison and CPU vs GPU performance analysis.

Best Model Results

  • MNIST: 99.12% accuracy (ResNet-18, BS=32, Adam, LR=0.0001)
  • FashionMNIST: 90.67% accuracy (ResNet-18, BS=16, Adam, LR=0.0001)
  • GPU Speedup: 7.45x for ResNet-18, 12.13x for ResNet-50

Key Learnings

Deeper networks like ResNet-50 don't always outperform simpler architectures; ResNet-18 achieved better accuracy with 2.27x fewer FLOPs on these datasets. Adam optimizer provides robust convergence across learning rates, while SGD requires careful tuning. GPU acceleration becomes increasingly beneficial with larger models, achieving up to 12x speedup. The choice of hyperparameters (batch size, learning rate, optimizer) has a more significant impact on model performance than architectural depth for simpler classification tasks.
